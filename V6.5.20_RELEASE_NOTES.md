# ApartCare Lite V6.5.20

## Production fixes and usability improvements

### Build fix
- Fixed the V6.5.19 JSX syntax error in the sidebar user-language block.
- Kept user-level language preference intact.

### Login without memorizing Account Number
- Apartment Account Number is now optional at login.
- User can authenticate with registered User ID, Email, or Mobile Number.
- If the same identifier/password combination is valid in multiple apartment accounts, the API returns only those authenticated matching accounts and the UI asks the user to select the apartment.
- Selecting an apartment retries the login against the chosen tenant.
- Account Number is still supported for direct login.
- Tenant isolation is preserved; no account list is returned for an invalid credential pair.

### Utilities
- Added a Call badge for utility contacts using the device `tel:` handler.
- Call is available to Admin, Viewer, Supervisor and Caretaker users who can access Utilities.
- Edit/Delete actions remain governed by existing role permissions.
- Edit/Delete controls are stacked vertically for a cleaner card layout.

### Build warning
- Set `outputFileTracingRoot` to the project root in `next.config.mjs` to prevent Next.js from selecting an unrelated parent lockfile as its workspace root.

## Core functionality protection
No changes were made to maintenance, payment, expense, dashboard, report calculations, tenant financial data, or cross-module business formulas. Login resolution and utility presentation are isolated from those modules.
