# V6.5.13 Core Functionality Fix 3

## Purpose
Fix Vercel production API invocation failures without changing UI or business functionality.

## Changes
- Do not write PostgreSQL state during FastAPI module import on Vercel.
- Keep local-development state persistence unchanged.
- Add a compatibility middleware that strips the public `/api` prefix before existing FastAPI route matching.
- Make `/api/health` perform a safe PostgreSQL connectivity check and return a diagnostic 503 instead of crashing.
- Preserve existing account, Platform Owner, Admin, Viewer, tenant, maintenance, payments and expense logic.

## Expected API checks
- GET `/api/health`
- GET `/api/account/status`
- GET `/api/platform/status`
- POST `/api/platform/bootstrap`
- POST `/api/platform/login`
- POST `/api/account/create`
