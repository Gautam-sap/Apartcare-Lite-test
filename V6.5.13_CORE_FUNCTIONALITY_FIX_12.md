# ApartCare Lite V6.5.13 — CORE FUNCTIONALITY FIX 12

Focused Fix 12 for the current Vercel test deployment.

## 1. Password-change behavior
- Normal Platform Owner creation/login does not force a password change.
- Normal Admin creation/login does not force a password change.
- Existing persisted users with the legacy first-login flag are cleared only when `created_at == updated_at`.
- Explicit password resets still set `force_password_change=True`.
- Logout explicitly clears the client-side password-change modal state.

## 2. Platform Owner login
- Platform login defensively clears only the legacy first-login flag.
- Normal credentials remain unchanged.

## 3. Cloud/local layout consistency
- Apartment identity header is explicitly rendered as a horizontal flex row.
- Apartment identity and ApartCare Lite logo/name/tagline remain side-by-side.
- Dashboard donut wrapper now explicitly uses CSS Grid; both charts render side-by-side on desktop/tablet widths.
- Mobile fallback stacks only when the viewport is genuinely narrow.

## 4. Scope
- No tenant/business calculation changes.
- No subscription calculation changes.
- No database schema changes.
- No Vercel routing changes.
- No UI module redesign beyond deterministic layout rules above.
