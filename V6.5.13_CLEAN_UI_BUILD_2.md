# ApartCare Lite V6.5.13 — CLEAN UI BUILD 2

## Changes
- Compact horizontal desktop workspace with consistent page margins.
- Smaller responsive KPI cards at 100% browser zoom.
- True circular dashboard donut charts with fixed aspect ratio.
- Platform Owner secondary header no longer duplicates the ApartCare logo.
- Platform Owner brand/security/user information arranged in a clean horizontal hierarchy.
- Subscription & Billing supports Product Owner-created Trial Plans with duration + Days/Months/Years unit and explicit assignment to accounts.
- Existing tenant accounts are repaired into Subscription & Billing when legacy state has no subscription row.
- Platform recovery refreshes account/user details when the tab is opened.
- Audit history refreshes when the Audit tab is opened.
- Tenant login/logout now writes audit records consistently.
- Cloud Postgres state version checks are cached for 1 second and the connection pool stays warm to reduce repeated request latency.
- Platform login loads the account workspace first; billing/audit/recovery load on demand.
