# ApartCare Lite V6.5.13 — CORE FUNCTIONALITY FIX 9

## Purpose
Surgical Vercel runtime fix only. No UI, tenant, account, login, maintenance, payment, expense, report, or business calculation changes.

## Root cause fixed
Vercel Services executes the backend under `/var/task`, which is read-only. The previous backend could fall back to `Path(__file__).parent` and then execute `TEMPLATE_DIR.mkdir(...)`, causing:

`OSError: [Errno 30] Read-only file system: '/var/task/app/templates'`

## Fix
- Detect `/var/task` directly in addition to Vercel environment variables.
- Use `/tmp/apartcare` only for runtime-writable data and uploads.
- Never create the bundled `templates` directory at runtime.
- Mount templates only when a bundled templates directory exists.
- A missing optional templates folder no longer prevents FastAPI from importing.
