# ApartCare Lite V6.5.13 — UI Alignment Fix 4

## Purpose
Client-trial visual polish and alignment hardening, with focus on consistent first-glance presentation.

## Changes
- Fixed the Administrator **Initial Password / Confirm Password** row so both password controls start at the same vertical position when the Initial Password helper text wraps.
- Added an explicit helper-text spacer to the Confirm Password field so the two-column form remains visually balanced.
- Kept password eye controls aligned with their corresponding input heights.
- Added final form normalization for Resident, Utility, Go-Live and Expense forms to prevent control overflow and grid-cell misalignment.
- Added table overflow protection for module tables so wide tables scroll inside their containers instead of breaking page layout.
- Preserved responsive one-column behavior on small screens.

## Backend / business logic
No backend, API, authentication, tenant-isolation, database, calculation or business-rule code was intentionally changed.
