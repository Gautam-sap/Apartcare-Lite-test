# ApartCare Lite V6.5.13 — Core Functionality Fix 4

## Root cause addressed
Fix 3 still performed `_load_state()` during Python module import. When Vercel has DATABASE_URL configured, that path can open a Postgres connection before the requested HTTP endpoint is reached. A failure/timeout at function initialization can surface as `500 FUNCTION_INVOCATION_FAILED`.

## Fix 4
- No Postgres state load during Vercel module import.
- Postgres state is loaded only by the existing per-request middleware.
- Local development still loads and persists JSON state at startup.
- Database connect timeout reduced from 10 seconds to 3 seconds.
- No frontend/UI changes.
- No business calculation changes.

## Deployment test order
1. Deploy with Vercel Services.
2. Test `/api/health`.
3. Expected result: HTTP 200 if DB is reachable, or HTTP 503 JSON if DATABASE_URL is configured but unavailable.
4. Only after health works, test Platform Owner creation.
5. Then test Apartment Account/Admin creation.
