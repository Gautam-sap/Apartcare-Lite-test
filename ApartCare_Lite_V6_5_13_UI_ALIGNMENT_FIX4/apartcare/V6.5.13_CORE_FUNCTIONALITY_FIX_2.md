# ApartCare Lite V6.5.13 — Core Functionality Fix 2

## Purpose
Fix the production 404 on `/api/account/create`, `/api/platform/login`, and `/api/platform/bootstrap`.

## Root cause
The previous deployment used the obsolete `experimentalServices` configuration and did not expose the FastAPI backend through the public `/api/*` routing table. The Next.js frontend therefore handled the API URLs and returned 404.

## Fix
- Uses the current Vercel `services` configuration.
- Routes `/api` and `/api/*` to the FastAPI backend service.
- Routes all other paths to Next.js.
- Uses `app.main:app` as the backend entrypoint.
- Adds a small ASGI boundary middleware that strips the public `/api` prefix before FastAPI route matching, preserving all existing backend endpoints without rewriting the application.
- No business logic or UI/CSS changes.

## Required Vercel setting
Project Settings → Build and Deployment → Framework Preset: **Services**.

## Smoke tests

2. `GET /api/account/status` must return JSON.
3. Platform Owner creation.
4. Apartment Account creation.
5. Admin login.
