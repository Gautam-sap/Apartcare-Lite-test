# ApartCare Lite V6.5.22 — UI, Tenant-Scoped Language & Recovery Hardening

- Professional apartment account selection cards with explicit name/account/location hierarchy.
- Expanded payment/maintenance static UI translation dictionary, including Payment Month and table headers.
- Tenant-scoped language preference resolution and persistence; no cross-tenant language propagation by user ID.
- Property session actor resolution now prefers tenant_sessions namespace, preventing stale global user copies from overriding the authenticated tenant.
- Platform Owner Tenant & Admin Password Recovery converted to a professional responsive data table with apartment/account, user, role, contact, status, last activity, audit count and actions.
- Legal checkboxes use deterministic custom 16x16 controls so browser/global styles cannot enlarge them.
- Language preference persistence moved to background state save to reduce UI wait time.
- Backend health version updated to 6.5.22.
- Core calculations, tenant middleware, navigation and business APIs are unchanged by these UI/auth-scope fixes.
