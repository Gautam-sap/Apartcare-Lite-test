# ApartCare Lite V6.5.13 — CLEAN UI BUILD 4

## Changes

- Subscription & Billing no longer assigns a plan when the plan dropdown changes. Product Owner selects a plan and must click **Assign**. Every successful assignment is recorded in per-account Subscription History.
- Existing account subscription rows remain tenant-scoped.
- Fixed the Utility **Add Category** action: clicking it now opens a visible category input/editor.
- Standardized the property sidebar workspace height/scroll behavior and increased navigation touch/visual spacing.
- Standardized the property Logout button with the application action-button design language.
- Platform Owner authenticated header now suppresses the duplicate brand/logo block.
- Tenant login audit records are persisted immediately after successful login so Login & Administration History survives serverless instance changes.
- Settings address loading is tenant-scoped and authenticated; an apartment account's creation address remains the default operational Settings address for that tenant. Cross-tenant address fallback is rejected.
- Remember Account Number & User on this device clears the saved identity immediately when switched off; password is never stored by ApartCare application storage.
- Email functions remain SMTP-configurable for welcome emails and password reset. Production SMTP variables must be configured in Vercel; no password/secret is stored in source code.

## Validation

- `python -m py_compile backend/app/main.py` passes.
- Full Next.js build requires Node dependencies and must be run by Vercel or a local Node environment with `npm install` completed.
