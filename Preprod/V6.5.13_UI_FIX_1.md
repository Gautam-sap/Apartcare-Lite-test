# ApartCare Lite V6.5.13 UI Fix 1

## Fix
Fixed form-control overflow in the Apartment Account / Apartment Profile two-column form.

### Root cause
The `.auth-form` uses a two-column CSS grid while its inputs/selects had `width:100%` plus padding and borders without `box-sizing:border-box`. This caused controls to extend beyond their grid tracks and visually overlap the adjacent field.

### Changes
- Added `box-sizing:border-box` to auth-form inputs/selects.
- Added `max-width:100%` and `min-width:0` to prevent grid overflow.
- Added `min-width:0` / `box-sizing:border-box` to auth-form labels and password fields.
- No API, database, authentication, tenant-isolation, or business-logic changes.
- Mobile one-column behavior remains unchanged.
