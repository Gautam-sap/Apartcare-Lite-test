# ApartCare Lite V6.5.13 — UI Alignment Hardening

## Fixed
- Platform Owner setup/login form labels and controls now use a strict vertical label-over-input layout.
- Platform Owner password field and eye button are aligned in a stable two-column control.
- Platform Owner setup form uses a consistent 2-column grid on desktop and 1-column grid on mobile.
- Resident, Utility and Go-Live forms now explicitly enforce vertical label/control alignment and full-width controls.
- Form action rows are kept on their own full-width grid row.
- Prevented inputs from overflowing or sitting beside their labels due to CSS cascade conflicts.

## Scope
This is a UI/CSS-only alignment hardening change. Application business logic, API calls, tenant isolation logic, authentication logic, calculations and database behavior were not intentionally changed.

## Validation
The source was inspected across the shared form CSS and module form structures. A local production build could not be completed in this environment because dependency installation timed out; run `npm install` followed by `npm run build` locally before deployment.
