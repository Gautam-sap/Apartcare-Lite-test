# ApartCare Lite V6.5.13 — CLEAN UI BUILD 3

## Platform Owner Console / Cloud Reliability Fixes

- Removed duplicate ApartCare logo from the authenticated Platform Owner console.
- Consolidated Platform Owner branding into one horizontal header row.
- Subscription & Billing now repairs/migrates missing subscription rows for every existing apartment account before rendering the account table.
- Create New Plan uses an explicit in-flight state, validates Trial duration, updates the UI immediately after a successful API response, and keeps Trial duration/unit part of the created plan.
- Added per-apartment Subscription History view for plan assignment, trial and lifecycle changes.
- Existing accounts are represented in Apartment Accounts, Subscription & Billing, User Recovery, and Global Login & Audit History.
- Platform audit rows now resolve Account Number and Apartment Name for tenant-specific platform events.
- Validity History creates a per-account baseline if a legacy account has no history.
- Platform Owner, tenant, and Audit/Support session registries are persisted with cloud state so Vercel instances can resolve authenticated actions consistently.
- Added client-side action locking to prevent accidental double-click / duplicate API submissions for Platform Owner actions and loaders.
- Subscription plan prices are saved on blur instead of issuing an API request on every keystroke.
- "Remember Account Number & User on this device" now remembers only Account Number + User ID in localStorage. Password is never stored by ApartCare application storage.
- Existing operational modules, tenant calculations, payment/maintenance/expense data structures and cross-module calculations are not changed by these Platform Owner fixes.

## Validation

- `python -m py_compile backend/app/main.py` passes.
- Full Next.js production build must be run in Vercel/Node environment with project dependencies installed.
