# ApartCare Lite V6.5.13 — CORE FUNCTIONALITY FIX 8

## Purpose
Surgical deployment fix for the Vercel read-only filesystem failure.

## Root cause addressed
The deployed FastAPI core was attempting to create runtime directories under `/var/task/app/templates`, which is read-only on Vercel.

## Fix
- Vercel/serverless runtime directories are forced under the operating system temporary directory (`/tmp/apartcare`).
- `__file__` is never used to derive writable runtime paths on Vercel.
- `APARTCARE_*` runtime path overrides remain available only for local development.
- Existing application routes, authentication, tenant logic, calculations, UI, and database logic are unchanged.
- Health response includes `build: CORE_FUNCTIONALITY_FIX_8` for deployment verification.

## Required verification
1. Deploy this exact source.
2. Open `/api/health` and confirm HTTP 200 and `build: CORE_FUNCTIONALITY_FIX_8`.
3. Open `/api/platform/status` and confirm `core_loaded: true`.
4. Only then test Platform Owner creation, Account creation, and Admin login.
