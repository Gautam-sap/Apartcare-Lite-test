# ApartCare Lite V6.5.13 — CORE FUNCTIONALITY FIX 11

## Core functionality fixes
1. **Cloud response time** — replaced the previous full PostgreSQL JSON-state reload on every request with a lightweight state-version check. A full state reload happens only when another Vercel instance has committed a newer state version.
2. **Password prompts** — initial Platform Owner and newly-created Admin passwords are normal passwords. A forced password change is reserved for an explicit password reset. Existing Fix-10 initial-password flags are cleared only when the user has never had their password changed.
3. **Apartment Account creation** — frontend now accepts the direct `TenantAccount` response returned by `/api/account/create`.
4. **Platform Owner Console consistency** — state version checking keeps warm Vercel instances synchronized after account/password/subscription changes.
5. **Subscription policy** — new accounts inherit the Product Owner's selected **Default Plan**. Trial is optional and is never silently assigned unless the Product Owner explicitly enables it.
6. **Legacy trial setting** — an unmodified legacy `system` subscription setting is migrated to Trial disabled; an explicitly saved Product Owner setting is preserved.
7. **Platform Owner login** — Accounts, Audit History and Subscription data are loaded in parallel.
8. **Dashboard KPI layout** — six KPI cards are explicitly horizontal on desktop and responsive on smaller screens.
