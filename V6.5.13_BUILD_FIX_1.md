# V6.5.13 Production Trial — Build Fix 1

Fixes included in this deployment build:

- Platform Owner / Super Admin session timeout now resolves to the `super_admin` rule.

Deployment root:

## Build Fix 2 — PasswordCredential TypeScript Compatibility

- Fixed Vercel/Next.js TypeScript error `Cannot find name 'PasswordCredential'` in the login remember-control path.
- The browser Credential Management API is now accessed dynamically through `window` so TypeScript does not require a `PasswordCredential` global type.
- Passwords are not written to ApartCare localStorage; only the account/user login hint is stored when Remember is enabled.
