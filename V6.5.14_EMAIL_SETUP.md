# V6.5.14 Email Setup

ApartCare Lite uses `apartcarelite@gmail.com` as the default sender for:

1. New apartment account welcome email.
2. New property-user welcome email.
3. Password-reset email.
4. Platform Owner welcome/reset email.

## Gmail requirements

- Use the `apartcarelite@gmail.com` mailbox.
- Enable Google 2-Step Verification.
- Create a Google App Password for ApartCare Lite.
- Never commit the App Password to GitHub.

## Environment variables

```text
APARTCARE_SMTP_SENDER=apartcarelite@gmail.com
APARTCARE_SMTP_EMAIL=apartcarelite@gmail.com
APARTCARE_SMTP_HOST=smtp.gmail.com
APARTCARE_SMTP_PORT=587
APARTCARE_SMTP_APP_PASSWORD=<16-character Google App Password>
```

Set these variables in the backend production environment (Vercel Project Settings for the Vercel test deployment, or the production backend service).

## Production database

Set `DATABASE_URL` to the Supabase Postgres connection string. ApartCare V6.5.14 rejects production write operations when a Vercel deployment has no persistent database configured.
