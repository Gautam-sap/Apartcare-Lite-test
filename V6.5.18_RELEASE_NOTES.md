# ApartCare Lite V6.5.18

- Tenant Language now controls the application font stack for English, Telugu, Hindi, Tamil and Kannada across the app. The selected language is applied when the tenant settings load and after Settings are saved.
- Fixed the password-change/modal backdrop so it covers the entire viewport, including the sidebar, eliminating the partial-screen/blank-background appearance seen during forced password change and refresh.
- Hardened checkbox/radio sizing to exactly 16x16px with no transform/zoom scaling, addressing oversized checkbox rendering in Settings and other modules.
- Existing V6.5.17 import validation and WhatsApp report readability fixes are retained.
- SMTP remains environment-configured; no email password is stored in frontend source.

## Language scope
The current change switches the font family/locale for the entire tenant UI based on the saved Language setting. It does not auto-translate existing English labels; adding full UI translation dictionaries is a separate localization phase.
