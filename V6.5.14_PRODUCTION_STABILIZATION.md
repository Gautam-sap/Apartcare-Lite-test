# ApartCare Lite V6.5.14 — Production Stabilization

## Core scope
- Tenant isolation is authoritative: property reads and writes resolve `tenant_id` from the authenticated session.
- Browser-supplied `tenant_id` / `apartment_id` values cannot switch a session into another account.
- Apartment photo upload is forced into the authenticated tenant namespace.
- Property reporting, dashboard, payments, expenses, maintenance, residents, settings and opening-balance reads are authenticated and tenant-scoped.
- Runtime version identifiers are 6.5.14.

## Regression gates
1. Account A has unique Maintenance, CCA and Opening Balance values.
2. Log into Account A and verify those values.
3. Log out and log into Account B.
4. Verify Settings, Dashboard, Maintenance, Payments, Expenses, Utilities and Reports contain only Account B data.
5. Attempt a request using Account B token with Account A `tenant_id` / `apartment_id`; API must return HTTP 403.
6. Upload/remove apartment photo in Account B and verify Account A is unchanged.
7. Generate a water report and verify Per Unit Price rounds upward (57.39 -> 58).
8. Print All Flats Monthly Report and verify only Water Summary + Water Detail table are printed.
9. Verify first-login password change and password reset email flow.
