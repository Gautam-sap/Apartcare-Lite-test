# ApartCare Lite V6.5.14 — Production Stabilization

## P0 Tenant Isolation
- Settings and all property reads resolve the authenticated tenant namespace.
- New tenants start with Common Maintenance = 0, CCA = 0 and Watchman Salary = 0 until explicitly saved.
- A settings response whose tenant does not match the authenticated tenant is rejected by the UI.
- Tenant financial defaults with no charge history are reset to a clean slate during state migration.

## Authentication
- First-login password change is mandatory for newly created property users and administrator-initiated password resets.
- Legacy state migration no longer silently clears the first-login flag.
- Password reset and welcome email flows use `apartcarelite@gmail.com` as the sender default.

## Caretaker Role
- New `Caretaker` role is tenant/account scoped.
- Access: Monthly Maintenance, Payments and Expenses.
- Operational create/update/delete actions are allowed in those modules.
- Lock/unlock controls remain Admin-only, including global financial month locks and expense locks.

## Performance
- Login and logout no longer wait for full state persistence; persistence is scheduled after the response.
- Tenant subscription loading is no longer on the critical login path.

## Reports / UI
- Dedicated A4 water-report print sheet removes hidden-layout whitespace and horizontal overflow.
- Print includes apartment branding left, ApartCare Lite + tagline + GKMA Solutions right, horizontal financial KPI cards, Water Summary and detail table.
- Apartment profile photo is standardized to 105 × 124 px on application pages.
- Mandatory form fields display a red `*`.
- Checkbox size is standardized to 16 × 16 px.
- Meter water rate is rounded up to the nearest whole rupee (e.g. ₹57.39 → ₹58), including persisted-rate migration.
