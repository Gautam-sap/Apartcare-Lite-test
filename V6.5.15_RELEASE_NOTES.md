# ApartCare Lite V6.5.15

## Included fixes

- Fixed report printing by rendering dedicated print-only report sheets outside scrollable screen containers.
- Collection vs Expenses yearly print now contains the report title, KPI cards and Monthly Financial Movement table.
- Individual Flat Statement print now contains flat details, statement table, totals and KPI summary.
- Removed application/sidebar/scroll-container layout from print output and constrained print content to A4.
- Increased Payment Collection Status and Mode column widths only enough to fit the text cleanly.
- Added bulk payment save endpoint so Save Selected submits all selected flats in one request instead of sequential requests.
- Payment saves now persist state in the background and refresh Payments + Dashboard in parallel.
- Added direct bundled Excel templates to Data Import for Resident Master and Historical Monthly Data.
- Added Administration > Mail Testing to queue a test email to the logged-in Administrator's registered email.
- Reduced login/session bootstrap latency by parallelizing initial status/session requests and removed unnecessary subscription loading from login.
- Kept tenant-scoped calculations, payment summary, Dashboard KPI formulas and cross-module report sources unchanged.
