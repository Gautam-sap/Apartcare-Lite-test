# ApartCare Lite V6.5.13 – Build Fix 2

## Fixed
Resolved the TypeScript error in `app/page.tsx` where a conditional request-header object inferred the `X-ApartCare-Token` property as `string | undefined` and was rejected by `fetch`'s `HeadersInit` type.

The watchman loader now explicitly declares the request headers as `HeadersInit`:

`const headers: HeadersInit = token ? {'X-ApartCare-Token': token} : {};`

## Scope
- Build/type fix only.
- No tenant-isolation or business-logic changes.
- No password storage changes.
