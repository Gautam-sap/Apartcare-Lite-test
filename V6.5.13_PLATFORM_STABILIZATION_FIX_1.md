# ApartCare Lite V6.5.13 — Platform Stabilization Fix 1

## Fixed in this build

1. **Subscription / Trial lifecycle**
   - Explicit Trial plans remain Trial plans when assigned.
   - Legacy zero-cost plans named Trial/Trail are treated as Trial plans instead of incorrectly becoming PAST_DUE.
   - Reassigning the same active Trial is idempotent and does not create duplicate history entries.
   - Trial validity is populated immediately after assignment.

2. **Create Property User / Administration**
   - Administration user/history endpoints remain available for controlled account administration even if a subscription is temporarily restricted.
   - Login and user-creation audit records remain tenant + account scoped.
   - Administration history CSV filename generation bug fixed.

3. **Apartment Profile Photo**
   - Upload now persists state with `_save_state()`.
   - Blob storage is used when configured.
   - A tenant-scoped durable data-URL fallback is used when Blob storage is unavailable.
   - Photo preview works after upload and after refresh.
   - JPG/PNG/WEBP and 5 MB validation retained.

4. **Remember Account Number & User**
   - Only Account Number and User ID are stored by ApartCare.
   - Password is never stored by ApartCare application storage.
   - Remembered identity is restored after logout.
   - Browser password-manager behavior remains independent of ApartCare.

5. **Platform Owner actions**
   - Assignment buttons show an immediate busy state.
   - Duplicate clicks are blocked while the action is in progress.
   - Common Platform Owner buttons have consistent disabled/active behavior.

6. **Email**
   - Platform-created account welcome email is queued using the existing SMTP configuration path.
   - Actual delivery still requires the deployment SMTP settings/app password to be configured.

7. **Tenant safety / calculations**
   - No maintenance, payment, expense, dashboard, or report calculation logic was intentionally changed.
   - Tenant/account context remains authoritative through the existing middleware.
