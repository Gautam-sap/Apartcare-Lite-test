# ApartCare Lite V6.5.23 — Build Fix 2

Fixes the Next.js production build scanning the nested Capacitor TypeScript config.

The Android project is intentionally nested under `android-app/`, but Next.js can still include nested TypeScript files during its build/type-check pipeline. The Capacitor config therefore uses `// @ts-nocheck` so the web application's TypeScript build does not require the Android-only `@capacitor/cli` package from the web root. The Android project retains its own package.json and can install/use Capacitor CLI independently.

No application business logic, API, tenant isolation, calculations, navigation, or authentication code was changed by this build fix.
