# ApartCare Lite V6.5.14 — Production Polish

- Per Unit Price rounds up to the next whole value as requested (for example 57.39 → 58).
- Apartment profile photos are resized/compressed in the browser and displayed at a controlled size. Admin can Update or Remove the photo.
- First-time property users are forced to change their temporary/initial password before entering the application.
- Password reset and welcome-email framework remains tenant-scoped and uses SMTP environment variables.
- Report Image, Excel and WhatsApp exports include ApartCare Lite branding and GKMA Solutions.
- All Flats Monthly Report print view is limited to the Water Summary and Water Detail table with apartment branding on the left and ApartCare Lite/GKMA branding on the right.
- Frontend TypeScript and backend Python syntax checks completed.

## Email configuration
Set `APARTCARE_SMTP_SENDER`, `APARTCARE_SMTP_HOST`, `APARTCARE_SMTP_PORT` and `APARTCARE_SMTP_APP_PASSWORD` in the deployment environment. Never commit the SMTP app password.
