# ApartCare Lite V6.5.13 — CORE FUNCTIONALITY FIX 15

## UI / UX Alignment Hardening

This release is a frontend presentation/layout correction based on the cloud screenshots and the existing V6.5.13 application structure.

### Desktop layout
- Platform Owner login branding: logo + "ApartCare Lite Platform" title/subtitle/tagline are horizontal.
- Resident Add/Edit form: four-column desktop grid; remarks and actions span the form width.
- Monthly Maintenance Setup: compact four-column desktop grid.
- Water Calculation: compact four-column desktop grid.
- Payment Month toolbar: month selector, explanation and actions use compact horizontal layout.
- Payment summary cards: horizontal grid.
- Expense Month summary cards: four-card horizontal grid.
- Expense entry form: compact four-column desktop grid.
- Reports controls: input/select widths are constrained by data type rather than stretching across the page.
- Report tabs and period controls remain compact and horizontal.
- Dashboard KPI cards: six-column desktop layout; responsive breakpoints reduce to three/two/one columns.
- Dashboard donut panels: two columns on desktop.
- Settings, Administration, Utilities and Go-Live forms inherit the same compact multi-column system.
- Module/page title rows remain horizontal on desktop.

### Responsive behavior
- Desktop/tablet uses compact multi-column forms to reduce vertical scrolling.
- Below 800px forms and dashboard cards collapse to one column for usability.
- No backend API, database, tenant-isolation, authentication, calculation or business-rule changes were made in this fix.
