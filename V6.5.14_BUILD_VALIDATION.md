- Gmail sender defaults to `apartcarelite@gmail.com`.

## Final deployment validation

From the clean project directory run:

```bat
npm install
npm run build
```

The build must finish without TypeScript or Next.js errors before pushing to GitHub/Vercel.

For production persistence, configure `DATABASE_URL` with the Supabase Postgres pooled connection string. Vercel production writes are intentionally blocked when persistent Postgres is not configured.
