# V6.5.23 BUILD FIX 1

## Issue
The Next.js production build attempted to type-check `android-app/capacitor.config.ts` because the root `tsconfig.json` included all `**/*.ts` files. The web application's root package does not install `@capacitor/cli`, so the build failed with:

`Cannot find module '@capacitor/cli'`

## Fix
The root Next.js `tsconfig.json` now explicitly excludes `android-app`. The Android project remains a separate Capacitor project and keeps its own `package.json` with the Capacitor dependencies.

## Functional safety
No business logic, API routes, tenant isolation, calculations, authentication, navigation, or database code was changed by this build fix.
