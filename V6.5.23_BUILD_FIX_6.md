# ApartCare Lite V6.5.23 — BUILD FIX 6

## Changes
- Expanded presentation-layer translations for Dashboard KPIs, Payments, Expenses, Water Summary, report/table headings and common financial labels.
- Corrected Kannada Dashboard translation that was incorrectly using Tamil script.
- Added prefix-aware translation for dynamic labels such as “Dashboard for: 2026-10”.
- Made My Language a professional titled control consistent with Dashboard Period styling.
- Apartment multi-account login choices now use long, clearly structured selection buttons: Apartment Name → Account ID → Address/City/State.
- Added default-descending sorting with user-controlled ascending/descending toggle to Login & Administration History.
- Added default-descending sorting with toggle to Platform Owner Global Login & Audit History.
- Added Created and sortable Last Activity columns to Platform Owner Tenant & Admin Password Recovery.
- Default API fetches now use no-cache/no-store semantics to reduce stale refresh values.
- Android download link remains on the normal account login page; Platform Owner console is not the distribution entry point.

## Core functionality
No changes were made to payment, maintenance, expense, dashboard calculation, tenant-isolation, authentication, locking or navigation business rules.
