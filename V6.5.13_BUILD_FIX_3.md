# ApartCare Lite V6.5.13 — Build Fix 3

## Vercel TypeScript fix
Fixed the production build error:

`Property 'bill_path' does not exist on type 'Expense'`

The frontend `Expense` type now includes the optional receipt fields returned by the backend:
- `bill_path?: string`
- `bill_original_name?: string`

No expense calculation, tenant isolation, authentication, or business logic was changed by this fix.
