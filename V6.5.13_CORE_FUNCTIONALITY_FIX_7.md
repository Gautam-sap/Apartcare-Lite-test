# ApartCare Lite V6.5.13 — Core Functionality Fix 7

## Root cause
The deployed backend reported `OSError: [Errno 30] Read-only file system: /var/task/app/templates`. Fix 6 used `/tmp` by default, but environment variables could still override the runtime path.

## Fix 7
On Vercel, runtime paths are now hard-coded under `/tmp/apartcare`. `APARTCARE_RUNTIME_DIR`, `APARTCARE_UPLOAD_DIR`, and `APARTCARE_TEMPLATE_DIR` cannot redirect runtime writes into `/var/task`. Local development remains configurable. No frontend, database, tenant, authentication, or business calculation changes.

## Deployment gate
1. Deploy this package contents to the same GitHub service root.
2. `/api/health` must return 200.
3. `/api/platform/status` must return `core_loaded: true`.
4. Only then test Platform Owner creation, account creation, and login.
